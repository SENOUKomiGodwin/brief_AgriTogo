#  BriefAgri Togo

**BriefAgri Togo** est le site vitrine officiel présentant la plateforme **BriefAgri Togo**, une initiative dédiée à la mise en valeur, la transformation et la promotion des produits agricoles au Togo, ainsi qu'à la diffusion d'actualités du secteur.

---

##  Aperçu du Projet

Ce site vitrine permet aux utilisateurs de :
- Découvrir l'histoire, la vision et l'équipe derrière l'initiative via la page **À propos**.
- Explorer le catalogue des **produits agricoles** locaux (transformés, céréales, tubercules, condiments, etc.).
- Suivre les **actualités** du secteur agricole togolais.
- Entrer en **contact** avec l'organisation grâce à un formulaire dynamique connecté à Formspree.
- Bénéficier d'une expérience visuelle agréable avec la prise en charge d'un **mode sombre** (Dark Mode).

## 🛠️ Technologies Utilisées

- **HTML5 :** Structuration sémantique des pages.
- **CSS3 :** Mise en page responsive et personnalisée.
- **JavaScript (ES6+) :** Interactions dynamiques et bascule du mode sombre.
- **Formspree :** Traitement et envoi des formulaires de contact.
- **Vercel :** Hébergement et déploiement continu.

##  Lancement en Local

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/votre-utilisateur/brief_AgriTogo.git
   cd brief_AgriTogo
   ```

2. **Exécuter le projet :**
   - Aucune installation de dépendances Node.js n'est requise.
   - Ouvrez directement le fichier `index.html` dans votre navigateur ou utilisez une extension de serveur local comme **Live Server** sur Visual Studio Code.
